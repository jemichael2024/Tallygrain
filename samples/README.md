# Samples

Test micrographs used by the app's **Load a sample** menu. Credits and licences are in [CREDITS.md](CREDITS.md).

```
sem/   scanning electron micrographs (scale bar burned into the image)
tem/   STEM/TEM images exported from calibrated data files (no burned-in bar)
```

To add one, note the scale (bar length in nm and in px, or nm/px from the file), the instrument and mode, and where it came from. Only commit images you have the right to share. Unpublished lab images belong to that lab, so keep them in `samples/private/`, which git ignores.
